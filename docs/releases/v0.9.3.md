## What's changed

- If the selected regional font is already in a website's font list but appears after a conflicting CJK font or a generic family, the extension now moves the selected font to an effective position instead of skipping the element.
- Mixed-language detection now uses broader conservative Japanese character evidence and can use confirmed adjacent context for short ambiguous lines, while continuing to exclude forms common in Simplified or Traditional Chinese.
- Dynamic pages now keep an existing page-wide language choice when comments or feed items are expanded at the same URL. Newly displayed text is still corrected, while in-page navigation to another URL continues to trigger language detection.
- Internal language handling now shares one page result, one supported-variant check, and the same localized language names across the popup and site settings.
- Small text updates on dynamic pages now avoid scanning unrelated managed elements.

## Install

1. Download `cj-font-fallback-fix-0.9.3.zip` from **Assets** below.
2. Extract the ZIP.
3. Open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the extracted folder.
