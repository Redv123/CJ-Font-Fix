## What's changed

- Combined the two website-font preservation switches into one setting. It respects suitable fonts specified by a website whether the font is provided online or already installed. Existing preferences are carried forward: the combined setting stays on if either former switch was on.
- A failed web-font face no longer counts as evidence that a website font can handle CJK text. Fonts split into on-demand Unicode subsets are still respected without downloading every subset.

## Install

1. Download `cj-font-fallback-fix-0.9.2.zip` from **Assets** below.
2. Extract the ZIP.
3. Open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the extracted folder.
