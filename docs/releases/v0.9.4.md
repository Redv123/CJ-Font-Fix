## What's changed

- Site language choices can optionally apply to a whole registered domain and its subdomains. Exact hostname choices take priority.
- A hostname can explicitly use automatic detection even when its domain has a saved language choice. Removing the hostname choice restores inheritance.
- Popup and Settings edits share a save queue. Renaming a rule cannot silently overwrite an existing rule.
- Existing site choices remain scoped to exact hostnames.

## Requirements

Chrome/Chromium 153 or newer. The new publicSuffix permission uses the browser's domain list for whole-domain matching.

## Install

Extract the release ZIP, then load the extracted folder through chrome://extensions in Developer mode.
