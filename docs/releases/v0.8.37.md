This is the first public release of CJ Font Fallback Fix.

The extension helps Chrome and Chromium choose the appropriate Simplified Chinese, Traditional Chinese, or Japanese font when a page has no useful language declaration. On Linux, it also addresses cases where bold CJK text is rendered with a Regular face. See the [README](https://github.com/Redv123/CJ-Font-Fix#readme) for details and limitations.

## Install

1. Download `cj-font-fallback-fix-0.8.37.zip` from **Assets** below.
2. Extract the ZIP.
3. Open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the extracted folder.

GitHub's automatically generated **Source code** archives are not the built extension.
