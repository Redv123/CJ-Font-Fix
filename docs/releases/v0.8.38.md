## What's changed

- Faster font processing on large or dynamically updated pages where many CJK text elements share the same CSS font stack. The extension now reuses the font decision within one processing pass instead of recalculating it for every matching element.
- The reuse ends with that pass, so later changes to a website's CSS or available fonts are evaluated again. On other pages, language detection, selected fonts, and the ordering of website-provided fonts are unchanged.
- When a page declares a specific Chinese or Japanese language and the trust setting is on, the extension now leaves all of its content to the browser, including nested or newly added content.

## Install

1. Download `cj-font-fallback-fix-0.8.38.zip` from **Assets** below.
2. Extract the ZIP.
3. Open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the extracted folder.
