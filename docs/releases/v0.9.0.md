## What's changed

- Experimental mixed-language detection now asks for confirmation in an animated warning dialog before it can be enabled. Canceling leaves it off; turning it off needs no confirmation.
- Improved Japanese detection on pages whose Chinese and Japanese language scores are close. Multiple distinct Japanese text segments can now resolve the page as Japanese, including titles that combine kana with Japanese-form kanji. This additional check does not treat a single Japanese title quoted in Chinese prose as page-level proof.
- In opt-in mixed-language mode, `々` now adds a small amount of Japanese evidence to ambiguous short lines. It cannot determine a line's language on its own.
- Opt-in mixed-language mode can use a clearly identified preceding paragraph to resolve a short neighboring Chinese or Japanese line when that line has matching clues. It does not carry uncertain guesses across multiple lines.
- Reworked the Settings font choices into a lighter row layout, with Sans and Serif side by side for each language and previews directly beneath their selectors. The default Chinese variant explanation also uses the available page width while its menu stays compact.

## Install

1. Download `cj-font-fallback-fix-0.9.0.zip` from **Assets** below.
2. Extract the ZIP.
3. Open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the extracted folder.
