## What's changed

- Fixed language detection after returning to a page within a single-page website. When a site reuses existing content instead of replacing its text, the extension now checks the current page again and restores the appropriate CJK font correction.
- Language declarations now prevent font correction only when they specifically identify Simplified Chinese, Traditional Chinese, or Japanese. English and other unrelated tags no longer block correction of CJK text; bare `zh` still needs Simplified/Traditional Chinese detection.

## Install

1. Download `cj-font-fallback-fix-0.8.39.zip` from **Assets** below.
2. Extract the ZIP.
3. Open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the extracted folder.
