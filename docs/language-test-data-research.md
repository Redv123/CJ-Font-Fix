# Language test data: provenance and release decision

Checked 2026-09-24. This note concerns test text, not a license change for the extension's code. A dataset's language label is not necessarily ground truth for the extension's **regional font** decision, and a sentence corpus does not replace browser tests of DOM sampling, CSS order, or rendered fonts.

## Candidate sources

| Source | Labels and usefulness | License and access | Repository decision |
| --- | --- | --- | --- |
| [FLORES-200](https://github.com/facebookresearch/flores/blob/main/flores200/README.md) | Explicit `zho_Hans`, `zho_Hant`, and `jpn_Jpan`; parallel sentences suitable for a balanced offline diagnostic. | Its [publisher](https://github.com/facebookresearch/flores/blob/main/README.md) and [dataset card](https://huggingface.co/datasets/facebook/flores) identify CC BY-SA 4.0 and request the NLLB paper citation. The Hugging Face files currently require accepting access conditions; the publisher also links a [direct archive](https://dl.fbaipublicfiles.com/nllb/flores200_dataset.tar.gz). | Use the official archive for an opt-in local browser benchmark. Do not copy its sentence text into this repository; record source, split, and license. |
| [FLORES+](https://huggingface.co/datasets/openlanguagedata/flores_plus) | Current OLDI successor: `cmn_Hans`, `cmn_Hant`, and `jpn_Jpan`; 997 `dev` and 1012 `devtest` sentences per language, with aligned IDs. | CC BY-SA 4.0, but access is gated. Its dataset card explicitly asks users **not to redistribute exported data publicly unless protected from automatic scraping** and says the data is for evaluation, not training. It requests citations for relevant papers. | Do not commit its sentence text, nor write a public-download CI step that bypasses its gate. Use only as a separately acquired, local, opt-in evaluation set after accepting its conditions. |
| [Tatoeba text exports](https://tatoeba.org/en/downloads) | Broad Japanese and Mandarin Chinese sentence coverage. Tatoeba labels Mandarin Chinese, **not** SC versus TC; script variant must be manually reviewed per selected sentence. | General text exports are [CC BY 2.0 FR](https://tatoeba.org/en/downloads); [Tatoeba's FAQ](https://en.wiki.tatoeba.org/articles/show/faq) asks for a Tatoeba link and license notice. The separate CC0 export exists, but the export checked on 2026-09-24 contained only two Japanese and one Mandarin sentence, so it is not useful for a representative CJK benchmark. Do not confuse text licensing with its separately licensed audio. | A future public regression set can select diverse CC BY sentences with IDs, export date, and attribution, then manually verify Chinese script labels. Do not claim that the nearly empty CC0 subset provides coverage. |
| [Lingua's evaluation method](https://github.com/pemistahl/lingua-rs#4-how-accurate-is-it) | Separates words, word pairs, and full sentences, and uses different source documents for training and evaluation. | Its benchmark text derives from Leipzig's Wortschatz corpora; the software's Apache license is **not** a blanket license for those source sentences. | Borrow the stratified evaluation method, not the test text, unless the upstream corpus terms are independently checked. |

For any CC BY-SA excerpt that is actually released, [Creative Commons](https://creativecommons.org/licenses/by-sa/4.0/) requires credit, a license link, indication of changes, and ShareAlike licensing for adapted material. Keep the data's provenance and license notice adjacent to the data. That does not, by itself, imply that all extension source code changes license; check the actual arrangement of copied/adapted material before release. The gated-host conditions are a separate concern from the public CC license.

## Practical evaluation design

1. Keep deterministic browser fixtures original and locally served: multiple independently written text blocks, real-looking `lang`/DOM/CSS patterns, mixed proportions, and font assertions. A sentence corpus alone cannot test these interactions.
2. If adding a publicly committed sentence suite later, use correctly attributed Tatoeba CC BY sentences. Store each source ID, declared language, human-reviewed expected `sc`/`tc`/`jp` or `unknown`, and a short reason for exceptions. Avoid duplicating one paragraph to manufacture a large sample.
3. Separate full-sentence, short-title, mixed-language, and ambiguous-Han strata. Report per-stratum confusion counts and abstentions; do not turn every failure into a hardcoded clue. SC/TC labels from Tatoeba must be review labels, not inferred from its `cmn` tag.
4. Run the optional FLORES-200 browser benchmark locally from its official archive, without committing data files. Record the source, `devtest` split, browser executable, and result. Keep it out of the default CI path; it samples translated single-language text, not realistic mixed websites.
